# Base de Dados

- https://www.kaggle.com/datasets/deepcontractor/aircraft-accidents-failures-hijacks-dataset
    - Conjunto de dados sobre acidentes, falhas e sequestros de aeronaves

    Acidentes e sequestros envolvendo aviões comerciais (com 12 ou mais passageiros), jatos executivos e aeronaves de transporte militar em todo o mundo desde 1919 a 2022.

# Como Fazer funcionar 

1. javac -d bin Src/*.java 
-d faz criar uma pasta e dentro dela vai ter todos os arquivos .class

2. java -cp bin Src.Main
-cp faz usar a pasta bin como caminho para executar os arquivos

3. Carregar a base de dados
